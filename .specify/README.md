# SpecKit: FirmLedger

This directory contains the specifications, constraints, and requirements for **FirmLedger**, following the Spec-Driven Development (SDD) standard.

## Specifications

* [`specs/comprehensive_system_spec.md`](specs/comprehensive_system_spec.md): Complete product & architectural specification covering data models, SQLite schema, Riverpod state providers, UI requirements, algorithmic debt payoff logic, and Gherkin acceptance criteria.

## Workflows Supported

* `/speckit.specify`: Author, review, and refine functional & technical specifications.
* `/speckit.plan`: Generate architecture design and implementation plans from approved specs.
* `/speckit.tasks`: Break down specifications into verifiable execution tasks.
